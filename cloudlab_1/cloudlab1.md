# Лабораторная работа: Анализ облачного биллинга

## Цель работы

1) Знакомство с облачными сервисами и принципами их потребления.
2) Формирование понимания уровней абстракции над инфраструктурой в облаке
и типов потребления сервисов в сервисной модели.

## Исходные данные

В качестве исходных данных использовался слепок биллинга облачного
провайдера AWS, представленный в виде CSV-файла. Значения в столбцах
Product Code и Usage Type содержат шаблоны с использованием символа `%`,
означающего произвольную последовательность символов.

## Ход работы

CSV-файл был импортирован в табличный редактор.
Далее строки биллинга были сопоставлены с документацией провайдера
и классифицированы по иерархии сервисов.

Для каждой строки были заполнены следующие поля:

- IT Tower
- Service Family
- Service Type
- Service Sub Type
- Service Usage Type

Классификация выполнялась от общего уровня к частному
(например, Compute → Amazon EC2 → Dedicated Host → Host usage).

Отдельно были выделены финансовые строки, не относящиеся
к фактическому потреблению ресурсов (налоги, подписки,
Savings Plans, разовые платежи).

## Результаты

В результате была получена структурированная таблица,
позволяющая анализировать потребление облачных сервисов
от общего уровня до конкретных типов использования.

## Вывод

В ходе работы было изучено устройство облачного биллинга,
различия между типами сервисов и уровнями абстракции,
а также принципы классификации потребления ресурсов
в облачной инфраструктуре.
